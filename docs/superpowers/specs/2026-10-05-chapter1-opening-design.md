# 《我不是戏神》像素同人游戏 · 第一章前三关 设计文档

> 日期：2026-10-05 · 状态：设计已逐段获玩家确认，待评审 spec
> 需求方与验收方是同一个人（玩家本人）。文中面向玩家的文案一律口语化。

## 0. 一句话

一个手机横屏、像素画风、类马里奥的**横版**剧情游戏，改编自三九音域的小说《我不是戏神》。本期只做第一章的**前三关**：开场动画「雨夜归来」、「剧场初演」、「醒来」。

## 1. 背景与已定决策

| 议题 | 决定 | 备注 |
|---|---|---|
| 题材 | 《我不是戏神》同人，**跟着书里剧情走** | 玩家是剧情顾问，剧情以玩家口述为准 |

## 3. 玩起来是什么样

### 3.1 画面规格

- 内部分辨率 **480×270**（16:9），整数倍放大铺满横屏，多出来的边用黑边填（letterbox）。
- 地图格子 **16×16** 像素；地面、墙、家具按格子画。
- **游戏内陈伶约 24×40 像素**（对话中使用的大头像另画，见 3.4）。
- 动作：**站立**（袖子轻飘，2~4 帧循环）、**走路**（4~6 帧）、**起跳**、**下落**、**落地**。
- 人物朝向随移动方向左右翻转。

### 3.2 操作

| 位置 | 按键 | 作用 |
|---|---|---|
| 左下 | ◀ ▶ | 左右走（按住持续走） |
| 右下 | 跳 | 跳跃 |
| 右下 | 互动 | 调查物件 / 推进对话。可互动物件在陈伶靠近时头上冒「!」 |
| 左上 | 暂停 | 暂停层：继续 / 回到标题 |
| 右上 | 跳过 | 仅在过场动画中出现 |

- 电脑：← → 走，空格跳，E 互动，Esc 暂停。
- 触屏按键支持**多点触控**（可以按住 ▶ 的同时按跳）。
- 对话框出现时：点屏幕任意处或按互动键推进；此时角色不可移动。

### 3.3 手感参数（初值，可调）

| 参数 | 初值 |
|---|---|
| 走路速度 | 90 px/s |
| 重力 | 900 px/s² |
| 起跳速度 | 300 px/s（约 3 格高） |
| 最大下落速度 | 400 px/s |
| 土狼时间（离地后仍可起跳） | 0.08 s |
| 跳跃缓冲（落地前按跳也算） | 0.10 s |
| 松开跳键提前截断上升 | 上升速度 ×0.5 |
| 物理步长 | 固定 1/60 s，渲染帧插值不做（像素游戏直接取整） |

### 3.4 对话框与头像

- 屏幕上方对话框（放在上方以免挡住人物；剧场关时让出右上角的期待值屏）：左侧 **48×48 像素头像** + 名字 + 文字逐字出现（可点一下直接显示全文）。
- 头像：**陈伶**（据先前定稿的像素立绘裁出头肩部，造型参考画师 @SYZDXZ 的同人图）、**李秀春**、**陈坛**。
- 陈伶的内心想法用无头像、斜体灰字的「想法框」。

### 3.5 存档

- 每过一关自动存（`localStorage` 键 `xishen:progress:v1`，内容 `{ v:1, level: 'opening' | 'stage' | 'home' | 'done' }`）。
- **读档容错**：读不到、格式不对、版本不对 → 一律当没存过，从头开始，绝不让游戏打不开。
- 标题画面：存档为 `opening` / `stage` / `home` 时显示「继续」与「从头开始」；「从头开始」需点两次确认（第一次按钮文字变为「再点一次确认」，3 秒后复原）。存档为 `done` 时只显示「从头开始」（无需二次确认）和一行小字「第一章前三关已通关」。没有存档时只显示「点击开始」。

### 3.6 标题画面

- 标题、一张场景图（雨夜街道 + 红衣背影）、「点击开始」。
- 底部小字：「同人作品 · 原作《我不是戏神》三九音域 · 非官方，不收费」。
- **第一次点击同时解锁声音**（iOS 要求声音必须由用户手势开启）。

## 4. 三关详细设计

### 4.1 关卡一：开场动画「雨夜归来」

全程为过场动画（可跳过）。台词是玩家口述的意思，**不使用小说原文**。

| # | 画面 | 声音 / 文字 |
|---|---|---|
| 1 | 黑屏 | 雨声渐入 |
| 2 | 远景：雨夜极光城街道，天上极光，空无一人 | 雨声 |
| 3 | 镜头横移：穿大红戏袍的少年踉跄走过泥水，袖子被风吹动 | 雨声、踩水声 |
| 4 | 家门前，停下，推门 | 开门声 |
| 5 | 屋内（切场景）：李秀春、陈坛站在客厅；镜头停在李秀春，眼眶通红；两人看到陈伶，惊恐 | 李秀春：「阿伶……你、你是怎么回来的？」 |
| 6 | 陈伶像没听见 | 陈伶：「好渴……家里有水吗？」 |
| 7 | 饮水机前，抱起水桶喝；咬碎桶口（桶口碎片 + 水花，**无血**）；切爸妈僵在原地 | 碎裂声、咕咚声 |
| 8 | 水桶喝干，一抹嘴，转身进房间关门 | 陈伶：「我先去睡了，爸妈你们也早点睡。」 |
| 9 | 镜头慢慢转回两人，长静默 | 只剩雨声；陈坛（压低声音）：「他是阿伶……那我们昨晚杀的，又是谁？」 |
| 10 | 黑屏 | 雨声渐出 → 进入关卡二 |

### 4.2 关卡二：剧场初演

**场景**：封闭舞台，横向约 2 屏宽（约 60 格）。
- 地板：老旧深棕木板，陈伶每一步发出「嘎吱」声。
- 聚光灯：从上方打一束白光，**慢半拍**横向追着陈伶；四周近乎全黑。
- 背景：一排排阶梯式抬高的观众席，只看得见密密麻麻的**红眼睛**，随机眨眼。
- 两侧与后方：封死的墙，走到边缘被挡住。
- 舞台边挂电子屏：红字「**观众期待值：29%**」，数字实时变化；左下小字「请不要让观众期待值低于 20%，否则剧院不保证演员的人身安全」。

**期待值规则**（纯函数模块，见 5.2；数值为初值，可调）：

| 项 | 规则 |
|---|---|
| 初值 | 29% |
| 范围 | 0% ~ 100%，越界截断 |
| 走动 | 有水平移动时 +0.25%/s（比下面的「看腻」只多一点点，单靠走动几乎不涨，逼玩家去找调查点） |
| 看腻 | 观众会慢慢看腻：每个 tick 无论动不动都 −0.21%/s（读想法时不 tick，所以暂停）；所以必须一直有新东西给他们看 |
| 跳跃 | 每次起跳 +1.5% × 0.5ⁿ，n = 过去 4 秒内的起跳次数（不含本次）；单次最少 +0.1%（「看腻了」；狂按跳每秒只涨约 0.2%） |
| 调查点 | 舞台上 **6 个调查点**（墙缝、左侧幕布后、右侧幕布后、台口边缘、假门、地板活板）。每个**首次**调查 +5%，并弹出一句陈伶的想法（如「这里也打不开……」）；再次调查只弹想法、不加分 |
| 发呆 | 无水平移动且在地面上**超过 1.5 秒**开始下降：1.0%/s 起，此后每多 1 秒速率 +0.5%/s，最高 4%/s；一旦移动或起跳，速率复位 |
| 危险 | 期待值 < 20%：屏幕边缘红晕、心跳声、红眼睛逐排向前凑近（按处于危险的时长插值） |
| 失败 | 连续处于 < 20% 满 **5 秒** → 灯灭、满屏红眼睛 → 从本关开头重来（不扣任何东西）。回到 ≥ 20% 时计时清零 |
| 过关 | 期待值 ≥ **70%** → 铃声响起 → 舞台分块碎裂 → 白闪 → 关卡三 |
| 反馈 | 每次加分，陈伶头上飘起「+N%」 |

**开场引导**：进入关卡时，陈伶的想法框依次弹出「这是……哪里？」「得找到出口。」，同时左右键和互动键轻微闪烁提示。

**目标时长**：2~3 分钟（6 个调查点 = +30%，29% → 59%，还差约 11%，要靠一路走动加适度起跳慢慢攒；观众会看腻，停下来或只顾查点都过不了关，6 个点缺一不可）。机器人模拟（`tests/scenes/stage-balance.test.ts`）：走完 6 个点后来回走、每 1.2 秒蹦一下的“好玩家”约 108 秒过关；少查 2 个点要 270 秒；查完站着不动约 40 秒失败；一开局就发呆约 12 秒失败。真人比机器人慢，实际落在 2~3 分钟。

### 4.3 关卡三：醒来

**场景**：陈伶家，横向一排三间：**卧室 → 客厅 → 厨房**，约 3 屏宽。清晨，灰暗冷色。

**流程**：
1. 陈伶在床上惊醒（短过场：坐起、喘气）。想法：「……是梦？」
2. 自由移动。可互动物件（每个 1~2 句想法，文案为原创）：
   - 卧室：窗户（窗外天色不对劲）、衣柜、床头
   - 客厅：空了的饮水机、爸妈卧室紧闭的门（**爸爸不在家**）、墙上的全家福
3. **幻觉事件**（按位置触发，各一次）：
   - 走到客厅中间：墙上一瞬间睁开一排红眼睛（约 0.5 秒）后消失，伴随低频音
   - 走进厨房门口：画面角落闪一下「观众期待值：??%」后消失
4. 厨房：地上碎掉的水桶；靠近后调查 → 低头特写：地上深红色、形状扭曲的痕迹（**暗示，不写实**）→ 画面定住 → 渐黑 → 「**第一章 · 未完待续**」→ 存档记为 `done` → 回标题。

## 5. 技术设计

### 5.1 技术栈与约束

- Vite 5 + TypeScript 5（strict）+ **Canvas 2D**（无引擎、无框架）+ Vitest/jsdom，Node 24。
- 构建为**单个 `index.html`**（`vite-plugin-singlefile`）：不加载任何外部资源。像素图在运行时用代码画到离屏 canvas；声音用 WebAudio 程序化合成。
- 渲染：离屏 480×270 canvas → 整数倍放大到屏幕 canvas，`imageSmoothingEnabled = false`，CSS `image-rendering: pixelated`。
- 竖屏时盖一层「请把手机横过来」。
- iOS「添加到主屏幕」全屏：`apple-mobile-web-app-capable`、`viewport-fit=cover`、主题色 meta；按键避开刘海安全区（`env(safe-area-inset-*)`）。

### 5.2 模块划分

纯逻辑模块全部 TDD、**不碰 DOM/Canvas**；渲染与 DOM 是薄层；`main.ts` 是唯一胶水。

| 模块 | 职责 | 依赖 |
|---|---|---|
| `src/input/actions.ts` | 统一动作状态 `{ left, right, jump, interact, pause }`，含「本帧刚按下」边沿 | 无 |
| `src/input/keyboard.ts` / `touch.ts` | 键盘、触屏按钮（多点触控）→ 写入 actions | actions |
| `src/physics/platformer.ts` | **唯一碰撞权威**：`step(state, input, dt, isSolid)`，逐轴 AABB 对瓦片碰撞、重力、土狼时间、跳跃缓冲、截断上升 | 无 |
| `src/actor/controller.ts` | 角色控制器：把 actions + physics 组合成「一个会走会跳的角色」，输出动画状态（idle/walk/jump/fall/land）与朝向。**不知道关卡、剧情、期待值的存在**——以后对战模式直接复用 | physics |
| `src/expectation/expectation.ts` | 期待值纯函数：`tick(state, events, dt)`，events = 移动中 / 起跳 / 首次调查；输出新值、危险计时、`status: 'ok' \| 'danger' \| 'failed' \| 'passed'` | 无 |
| `src/cutscene/runner.ts` | 过场剧本执行器：步骤数组（`fade` / `pan` / `cut` / `walk` / `say` / `think` / `wait` / `shake` / `sfx` / `anim`），逐步推进、可跳过（跳过 = 直接应用最终状态并结束） | 无 |
| `src/dialogue/dialogue.ts` | 对话框状态：逐字显示、点击补全、点击下一句 | 无 |
| `src/level/*.ts` | 关卡数据：瓦片图（字符串网格）、调查点、触发区、出生点；`stage.ts`、`home.ts`、`street.ts`（开场用） | 无 |
| `src/level/interactables.ts` | 靠近检测（谁头上冒「!」）、首次/再次调查判定 | 无 |
| `src/art/*.ts` | 像素图：以字符网格 + 调色板定义陈伶各帧、爸妈、头像、瓦片、观众红眼；运行时画到离屏 canvas 并缓存 | Canvas（薄层） |
| `src/audio/synth.ts` | WebAudio 合成：雨、嘎吱、心跳、铃、碎裂、开门、低频音 | WebAudio（薄层） |
| `src/save/progress.ts` | 存档序列化 + 容错读档 | 无（存储以参数注入） |
| `src/flow/game-flow.ts` | 关卡流程状态机：`title → opening → stage → home → done → title`；失败重开；过关存档 | 无 |
| `src/render/*.ts` | 相机跟随、瓦片绘制、角色绘制、聚光灯/暗角/红晕、HUD（电子屏、+N%）、对话框 | Canvas |
| `src/main.ts` | 接线 + 主循环（固定步长 1/60 累加器） | 全部 |

### 5.3 数据流

触屏/键盘 → `actions` → `controller`（→ `physics`）→ 关卡逻辑（调查点、触发区、期待值事件）→ `expectation` / `cutscene` / `dialogue` → `game-flow` → `render`。单向，每帧一遍。

### 5.4 错误处理

- 存档读写全部 try/catch；写失败（隐私模式等）静默忽略，不影响游玩。
- WebAudio 不可用或未解锁：所有声音调用变成空操作。
- 页面切后台（`visibilitychange`）：自动暂停，回来停在暂停层。
- 失焦/切后台时清空 actions，防止「卡键一直走」。

### 5.5 测试

- **单元测试（TDD）**：physics（落地、撞墙、顶头、土狼时间、跳跃缓冲、截断上升、高速不穿墙）、expectation（每条规则的边界：发呆 2 秒阈值、速率封顶、跳跃衰减与下限、调查点只加一次、危险计时清零、≥70 过关、5 秒失败）、cutscene runner（顺序、等待、跳过后终态正确）、dialogue（逐字、补全、推进）、interactables、save（坏档当没存过）、game-flow（全部状态转移）、actions 边沿。
- **接线断言**：沿用 voxel-builder 的经验，对 `main.ts` 中「纯函数 + 实参」的关键接线做源码级断言（先剥注释）。
- **变异纪律**：新增守卫时临时删掉它，确认至少一个测试变红。
- **目视验收**：在内嵌浏览器以手机横屏尺寸（约 812×375）逐关截图检查；最后玩家真机走查。

## 7. 验收标准（本期完成的定义）

1. 手机横屏打开网址，标题页点击后有声音，能「继续 / 从头开始」。
2. 开场动画 10 个镜头按 4.1 演出，台词一字不差，可随时跳过。
3. 剧场关：电子屏实时显示期待值；4.2 表中每条规则都可被观察到；能失败并重开；达到 70% 后铃响碎裂进入下一关。
4. 醒来关：可走完三间屋；至少 6 个可互动物件、2 个幻觉事件；厨房结尾出现「第一章 · 未完待续」。
5. 每关结束自动存档；刷新后「继续」回到对应关卡。
6. 触屏可同时按住方向键和跳；切后台再回来停在暂停层且不卡键。
7. 全部单元测试通过、typecheck 干净、构建产出单文件。
8. 已部署到 GitHub Pages，玩家真机玩通三关。
